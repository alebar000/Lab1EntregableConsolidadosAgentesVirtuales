# Insumos de Laboratorio - Agentes Virtuales

Este repositorio contiene la consolidación de los entregables y recursos generados por los estudiantes en la primera etapa de laboratorio del curso de Agentes Virtuales Inteligentes.

El propósito de este repositorio es facilitar la revisión cruzada y el intercambio de componentes técnicos (scripts, modelos 3D, enfoques de *embodiment*, etc.) entre los estudiantes para la siguiente fase del proyecto.

## Estructura y Limpieza

Para facilitar la descarga y evitar saturar el repositorio consolidado, se han eliminado de cada carpeta las bases de datos de Git internas (`.git`) y los archivos temporales pesados autogenerados por Unity (como las carpetas `Library`, `Logs`, `Temp`, y `obj`). Solo se conserva el código fuente, los recursos (`Assets`), documentación y configuraciones relevantes.
